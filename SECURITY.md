# Security policy

Report a security problem privately: on the [Security tab](https://github.com/CommitMaster102/snippet-inserter/security), click **Report a vulnerability**. Do not open an issue for it, because anyone can read issues.

Report, for example, a way for a web page to read stored snippets, to make the extension insert text the user did not pick, or to run code in the extension's own pages.

Fixes are released as a new version in the Chrome Web Store, and only the latest version gets them.
